# 日志分析工具（Log Analyzer）使用说明

一款面向生存战争游戏服务器日志的 **Windows 桌面异常分析工具**：导入 CSV / ZIP 日志后，
自动解析并检测异常行为（瞬移、加速、位置篡改等），支持实时筛选、明细表格、
摘要统计与报告导出。**无需安装任何环境，解压即用。**

---

## 一、运行要求

| 项目 | 要求 |
| --- | --- |
| 系统 | Windows 10 / 11，64 位 |
| 安装 | 无需安装任何软件（VC++ 运行库已随包内置） |
| 内存 | 建议 8GB 以上（百万级日志解析约占用 1~1.5GB） |

---

## 二、快速开始（30 秒上手）

1. **解压** 本压缩包到任意目录（整个文件夹解压，不要只拷 exe）；
2. **双击** `log_analyzer.exe` 启动程序；
3. **导入日志**，三种方式任选：
   - 点击 **「选择文件 (.zip/.csv)」**，用 Windows 文件对话框选择日志文件；
     - 选择 `.zip` 压缩包 → 自动解压到临时目录并解析其中所有 CSV；
     - 选择 `.csv` 单文件 → 直接解析；
   - 在顶部输入框粘贴 **ZIP 下载地址**（http/https），点击 **「下载」** → 自动下载并解压；
4. 等待解析完成（进度条提示），即可在下方三个页签中查看结果。

> 日志列格式要求：`timestamp,player_guid,player_name,action_type,detail`
> （兼容 UTF-8 BOM / GBK 编码，多余空行自动跳过）。

## 三、界面功能

### 筛选条（实时过滤，即输即筛）
- **玩家ID/名搜索框**：输入即过滤，支持模糊匹配；
- **事件类型下拉框**：按事件类型过滤（含「全部」选项）；
- **起始 / 结束时间选择器**：按时间范围过滤；
- **「仅显示异常」**：只保留被异常规则命中的记录；
- **清除筛选**：一键恢复全量视图。

### 三个页签
| 页签 | 内容 |
| --- | --- |
| **摘要** | 日志总行数、玩家数、异常数、时间范围等统计卡片 + 事件类型分布 + 规则触发概览 |
| **明细** | 全量明细表格（时间戳 / 玩家ID / 玩家名 / 事件类型 / 异常规则 / 详情） |
| **结论** | 异常关注点汇总（规则名称、触发次数、涉及玩家、示例、建议）与报告导出 |

### 明细表格操作
- **点击列头**：升序 / 降序排序；
- **拖动列头右侧边缘**：调整列宽；
- **点击行**：选中高亮；
- **右键任意行 → 「复制该行」**：以 CSV 格式复制到剪贴板，可直接粘贴到 Excel。

### 设置（右上角 ⚙ 图标）
- 每条异常规则可 **启用 / 禁用**，阈值可拖动滑块或直接输入调整；
- 表格最多显示行数可调整（大数据时建议保持默认或调小）；
- 修改后自动按新规则重新检测。

## 四、内置异常检测规则（阈值均可调）

| 规则 | 检测内容 | 默认阈值 |
| --- | --- | --- |
| 高频移动 | 同一玩家 1 秒内移动次数过多（疑似加速外挂） | > 8 次/秒 |
| 瞬移跳跃 | 相邻两次移动距离过大（60 秒内，疑似瞬移外挂） | > 200 格 |
| 位置篡改 | 服务端位置修正与已知位置偏差过大 | > 200 格 |
| 频繁进出游戏 | 60 秒内进入游戏次数过多（疑似刷资源） | > 5 次/分 |
| 未知玩家操作 | 玩家ID 为 unknown 却产生游戏内操作 | 出现即异常 |
| 死亡赔付爆发 | 10 分钟内死亡保护赔付次数过多（疑似刷赔付） | > 3 次/10分 |
| 领地倒液被拒 | 在他人领地周围倒液体被系统拒绝 | 出现即异常 |

## 五、报告导出

在 **「结论」** 页签点击：
- **导出 TXT**：完整分析报告（摘要 + 异常关注点 + 结论，明确列出触发的规则名称）；
- **导出 CSV**：当前筛选范围内的全部明细（含异常规则列，UTF-8 BOM，Excel 可直接打开）。

未选择保存位置时，默认保存到：`文档/LogAnalyzer/Exports/`

---

## 六、配置文件

- 设置文件：`文档/LogAnalyzer/settings.json`（规则开关、阈值、表格行数上限）；
- 下载 / 解压临时文件位于系统临时目录，重启或重导日志时自动覆盖，无需手动清理。

## 七、常见问题（FAQ）

**Q1：双击 exe 没反应或提示缺少 DLL？**
确认已解压**整个文件夹**（exe、flutter_windows.dll、data 目录须在同一目录下），
且系统为 Windows 10/11 64 位。VC++ 运行库已内置，纯净系统也可运行。

**Q2：被杀毒软件拦截 / 报毒？**
自编译程序可能被部分杀软误报，请将程序目录加入白名单后重新解压运行。

**Q3：日志很多，导入很慢 / 表格卡顿？**
解析在后台隔离线程执行，界面不会卡死；表格默认最多显示 20 万行，
命中更多时请用筛选缩小范围（或在「设置」中调整显示上限）。

**Q4：为什么我的日志导入后提示"列数不符"被跳过？**
程序严格按 5 列（timestamp,player_guid,player_name,action_type,detail）解析，
请确认 CSV 表头与列格式。

**Q5：异常检测结果和预期不符？**
阈值可在「设置」中调整后自动重新检测；规则说明见上表。
